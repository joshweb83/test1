# 🎮 테트리스 게임

재미있는 테트리스 게임이에요! 초등학생도 쉽게 즐길 수 있어요!

## 🌟 게임 특징

- 🎨 **예쁜 무지개색 블록** - 7가지 색깔의 블록들
- 🎯 **점수 시스템** - 줄을 없앨 때마다 점수가 올라가요
- 📈 **레벨 시스템** - 10줄을 없앨 때마다 레벨 업!
- ⌨️ **키보드 조작** - 화살표 키로 쉽게 조작
- 📱 **반응형 디자인** - 컴퓨터, 태블릿, 핸드폰 모두 OK!

## 🎮 조작 방법

- **⬅️ 왼쪽 화살표** - 블록을 왼쪽으로 이동
- **➡️ 오른쪽 화살표** - 블록을 오른쪽으로 이동
- **⬇️ 아래 화살표** - 블록을 빨리 떨어뜨리기 (보너스 점수!)
- **⬆️ 위 화살표** - 블록 회전하기
- **스페이스바** - 블록을 한 번에 떨어뜨리기

## 🎯 게임 규칙

1. 떨어지는 블록을 조작해서 한 줄을 채워요
2. 한 줄이 완성되면 그 줄이 사라지고 점수를 받아요
3. 여러 줄을 동시에 없애면 더 많은 점수를 받아요!
4. 10줄을 없앨 때마다 레벨이 올라가요
5. 레벨이 올라가면 블록이 더 빨리 떨어져요
6. 블록이 맨 위까지 쌓이면 게임 오버!

## 🚀 게임 시작하기

### 방법 1: 파일로 실행
1. `index.html` 파일을 더블클릭하세요
2. 웹 브라우저에서 열릴 거예요
3. "🎮 게임 시작" 버튼을 눌러요!

### 방법 2: 로컬 서버로 실행
```bash
python3 -m http.server 8000
```
그리고 브라우저에서 `http://localhost:8000` 로 접속하세요!

## 🌐 인터넷에 올리기 (무료!)

### Vercel로 배포하기 (추천!)

1. **Vercel 웹사이트 가기**: https://vercel.com
2. **GitHub 계정으로 로그인**
3. **"New Project" 클릭**
4. **이 GitHub 저장소 선택**
5. **"Deploy" 클릭!**
6. 완료! 🎉 친구들과 링크를 공유하세요!

### GitHub Pages로 배포하기

1. GitHub 저장소로 가세요
2. Settings → Pages 클릭
3. Source를 "main" 브랜치로 선택
4. Save 클릭!
5. 몇 분 후면 링크가 생성돼요!
