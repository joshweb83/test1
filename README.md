# 이구동성 게임

같은 주제에 대해 플레이어들이 동시에 단어를 적고,
몇 명이 같은 답을 적었는지 확인하는 웹 게임입니다.

## 기능
- 주제(문제) 입력
- 4명 플레이어 답변 입력
- 답변 공개 후 일치 인원 수 계산
- 전원 일치(이구동성) 여부 표시
- 같은 주제로 즉시 재도전

## 실행 방법
1. `index.html` 파일을 브라우저에서 엽니다.
2. 주제를 입력하고 **라운드 시작** 버튼을 누릅니다.
3. 플레이어 1~4의 답을 입력한 뒤 **정답 공개**를 누릅니다.

## 파일 구성
- `index.html`: 게임 UI
- `style.css`: 화면 스타일
- `script.js`: 게임 로직
